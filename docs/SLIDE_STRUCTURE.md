# スライド構成・表記ルール（2026-11-05）

最初の5枚はタイトルと概要／リード／はじめに／KP向け情報／PL向け情報。内容未定でも空欄で確保する。概要は400字程度で本編字数に含めない。リード以降が本編。
NPCは一人1枚、導入〜結末は1シーン1枚。備考は最後に置く。

表記は〈技能〉・〈正気度〉ロール、［計算式］、《呪文名》、『魔道書・書籍・映画タイトル』。
共通定義はlib/notation.ts。編集入力欄と相談文、MCPの初期案内・プロジェクト情報・制作規則取得結果に渡す。参照資料の原文は変更しない。

## 既存データの移行

lib/migration.tsは既存Storeを一度だけ移行する。本文・共通素材・設定・時系列・関係・課題・提案を保持し、元のDocと選択状態をStore.layoutBackupへ保存する。同時に履歴へ移行前のDocを記録する。
既存の概要はKP向け情報へ移動し、不足する冒頭ページは空欄で追加。共有NPCの既存情報を一人1枚に整理する。導入・探索・結末を保持し、補足資料は最後の備考へまとめる。原ページもDoc.legacyPagesに保持し、get_pageで旧IDを指定すれば取得できる。
未知の概要・リード・能力値や物語の接続を生成しない。旧設定の意味上の矛盾や採否を独断で変更しない。
保存時はDBの版番号で競合を検出し、最新データに対し原子更新する。取り消し後に同じ移行を繰り返さない。

## 検証

型検査、モデル・保存・移行テスト成功。移行の不変性・元文の保管・解決済み課題と提案の保持・並行読込の一度限りの更新・取り消しを検証。
現行データの取得可能範囲で13ページ・6素材への移行を検証。プレビュー画面と編集入力欄の表記案内を確認。

## 個人用・複数シナリオ（v0.3、2026-11-05）

公開範囲は所有者本人のみ。共有相手・外部訪問者を追加しない。Web上部のシナリオ名を押すと、作品の一覧・新規作成・切り替え・名前変更を行える。
新しいシナリオは空欄6枚で始まり、本文・共通素材・設定・時系列・関係・課題・AI提案・選択ページ・履歴を独立して保存する。既存の学園シナリオはmainとして保持。

保存先は既存studioテーブルのID別の行。__workspace行は最後に開いたシナリオIDだけを保持する。DBスキーマ追加・既存行の置換はしない。
画面はscenarioIdをすべての保存・読込へ付与し、URLにも保持。切り替え前に保存し、古いポーリング結果で別作品の画面が上書きされないようにする。読込途中の画像は対象が切り替わったら配置しない。
MCPはget_project_contextでシナリオ一覧と対象IDを返す。以後の作品固有の読み取り・提案にはscenarioIdを指定する。複数作品がある状態でIDを省略した操作はエラーにする。相談文と提案JSONにもIDを含める。Webの提案取込はID不一致を拒否。

型検査、保存・MCPルーティングのテスト、独立した新規作成・保存・提案採用・取り消し・選択ページの検証が通過。プレビューで別作品の作成・本文入力・元作品への切り替えを確認。動作確認用の別作品はローカル環境にのみ作成し、公開データには含めない。

## 自由な枠サイズ変更（2026-11-05）

本文・画像・NPCの配置枠はクリックして選択し、四隅と各辺の計8か所のハンドルからサイズを変えられる。上・左から変更すると位置も調整し、対向する辺は保持する。ページ内の範囲で最小20pxとし、ズーム率に応じてポインターの移動量を変換する。寸法はシナリオの配置情報として従来通り保存し、数値入力でも調整できる。

左右の素材・スライドパネルは境界のグリップをドラッグして幅を調整する。境界にフォーカスし左右キーでも調整可能。Shift併用で大きく移動、Homeまたはダブルクリックで標準幅へ戻す。中央に320px以上を残し、パネル幅は170〜640pxで調整する。パネル幅はブラウザのlocalStorageに保存する。

scripts/test-layout.mjsで8方向の対向辺保持・最小寸法・ページ境界・保存形式の妥当性・パネル幅の制約を検査。ブラウザでも左辺・下辺・左右パネルをドラッグし、再読込後の寸法とパネル幅の保持を確認。公開中のシナリオ本文は変更しない。

## スライド優先のコンパクト表示（2026-11-05）

上部バー40px、タブ32pxに縮小し、ページ名・相談・配置ツールを42pxの編集リボンに集約する。長いページ名は省略し、タイトル属性で全文を確認できる。文字サイズは操作ラベルを11〜12pxで維持し、余白と装飾の高さを削減する。
キャンバス周囲の余白、下部の案内・設計メモ・状態表示もコンパクトにし、全体表示は表示領域に合わせてスライドを拡大する。
集中表示は左右のパネルと上部タブを一時的に隠す。通常表示ボタンまたはEscで復帰する。パネル幅やスライドの内容・配置は変えない。
同じ1363×936の確認画面で、スライドは変更前617×347、通常表示757×426、集中表示1303×733。上部の編集用領域は271pxから114pxへ減少。タブの切り替えと復帰・集中表示・Esc解除・横方向のはみ出しがないことを確認。TypeScript型検査とビルドで検証する。
