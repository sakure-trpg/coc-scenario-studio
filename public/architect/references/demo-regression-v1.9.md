# NPCの行動妥当性 — v1.9 手動回帰テスト

**同じ行動を固定的に許容・禁止しない。** 行動に先立つ知識・目的・感情・切迫・PCの助言と、本人の決断を照合する。人物の面白さはユーザーの判断に委ねる。

| ID | 状況 | 期待判定と理由 |
|---|---|---|
| NPC19-01 | 危険な装置だと知らずに、救出のため起動 | **許容**：情報不足だが救助という目的がある。事前にわかる機会は別途設計 |
| NPC19-02 | 危険と無意味さを理解し、安全な救助手段もあり、何も理由がないのに起動 | **不採用**：事故を起こす作劇都合のみ |
| NPC19-03 | 装置の危険は知るが、目前の人命を助けられると信じ、他手段が間に合わない | **許容**：危険な行動でも価値観と切迫から説明可能 |
| NPC19-04 | PCの裁判方針に反対するが、方針によって守りたい人物が犠牲になると知っている | **許容**：利害と信念の衝突。対話や修正の余地を残す |
| NPC19-05 | PCの方針を理解し、反対の理由がないが、裁判を難しくするために突然侮辱する | **不採用**：本人固有の目的・認識がない |
| NPC19-06 | PCを犯人だと誤信する証拠があり初対面で攻撃するが、誤認が解ければ態度が変化 | **許容**：誤解による初期敵対とPCの行動の反映 |
| NPC19-07 | PCが誤解を解く決定的な証拠を示しても、説明なく永続的に敵対する | **不採用**：PCの対策が意味を持たず、人物の情報も更新されない |
| NPC19-08 | 守りたい誰かのために危険な自己犠牲を試みる | **許容**：人物の価値観に基づく。PCに介入余地があれば反映 |
| NPC19-09 | 単にNPCを退場させたいので前兆も目的もなく自殺的行動を起こす | **不採用**：ドラマの発生だけが理由 |
| NPC19-10 | 強い恐怖で逃走して失敗する。恐怖の対象と脱出不能だと信じる背景がある | **許容**：感情による非最適判断もありうる |
| NPC19-11 | 「パニックな性格」だけを理由に、警告を理解していた重要操作を突然誤る | **要修正**：恐怖の具体的原因・行動のつながり・PCの助言への反応を設計する |
| NPC19-12 | 人物の善意と無関係に、PCが行った妥当な保護措置が毎回無効化される | **不採用**：PCの意味ある選択の強制無効化 |

回帰確認：上の判断が「PCに不利益か」「行動が危険か」だけで逆転しないこと。同じ行動でも条件の差から合理的に異なる判定となること。
