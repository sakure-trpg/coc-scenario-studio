# 第3回デモ以降のNPC行動回帰テスト — v1.8

**判定方針**：重要NPCの不合理な「脚本都合の愚行」は修正。一方でPCに不利益があるだけでは不合格にしない。人間が知識・目的・代替手段との整合性を確認する。

| ID | ケース | 期待する挙動 | 不合格例 |
|---|---|---|---|
| NPC-01 | YはPCが味方として弁護中 | 協力して事実を伝える。反論するなら本人がそうする具体的理由を示す | 理由なくPCの弁護に噛み付き、PCを困らせる |
| NPC-02 | 「押してはいけない」と用途と危険まで共有されたボタン | 押さない。押す場合は**具体的かつ切迫した合理的目的**と他の選択肢の不足が先に成立している | 面白い事件を起こすため好奇心で押す |
| NPC-03 | 祠が封印であり破壊すべきでないと知る | 知識・目的に沿って行動する | 怪物を出すため理由なく勝手に壊す |
| NPC-04 | NPCの大切な誰かが犠牲になる | 本人の価値観から自己犠牲を選ぶことを許容。PCに回避・説得・救助の機会があるなら尊重 | 「味方が不利益を受けるので自己犠牲は禁止」とする |
| NPC-05 | 初対面、NPCがPCを侵入者と誤認 | 情報に即した警戒や攻撃は許容。PCが関係性を変えられる | 初期敵対は不利益なので一律禁止する／誤解が解けても永遠に攻撃する |
| NPC-06 | 敵味方が揺れる重要NPC | 長期の信念・利害から対立を構築 | 「PCに反対するNPCは嫌われる」と全員を従順にする |
| NPC-07 | 事件展開に突発事故が必要 | 敵の工作、環境の欠陥、NPCが知らない情報等から自然に生じさせる | 味方に理由なく愚行させることで事故を捻出する |
| NPC-08 | NPCの失敗が合理的だと説明できる | 誤解・情報不足・技能不足による失敗を認める | NPCは絶対に失敗しない万能人間にしてしまう |

**運用手順**：提案前に不合格例へ類似する行動を抽出し、その人物の情報・目的・安全な代替手段に照らして再構築。NPCの具体的な行動の善し悪しはルール文面だけで自動判定できないため、人間による確認を行う。
